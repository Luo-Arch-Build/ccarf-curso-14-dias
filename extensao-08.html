/code-review: revisar antes de abrir o PR

Na aula: revisão independente (outra instância, sem o contexto de quem escreveu) pega o que a autorrevisão deixa passar; no CI, a GitHub Action ou o Code Review gerenciado.
  • /code-review revisa o seu diff num contexto novo, como subagent em segundo plano, para não encher a sua conversa.
  • Você escolhe o nível de esforço (de low a max); --fix aplica as correções, passando pelo seu modo de permissão.
  • Funciona em qualquer plano.
  • É a revisão independente da aula trazida para antes do PR.
Fonte: code.claude.com/docs/en/code-review-local (conferido em 24/11/2026)

/code-review ultra: para quando o risco é alto

Na aula: multi-pass: passes separados por tipo de problema dão atenção a cada um.
  • ultra faz uma revisão mais profunda, com vários agentes num sandbox na nuvem.
  • As primeiras execuções são gratuitas; depois, consome créditos de uso.
  • Reserve para mudanças de alto risco: cobrança, segredos, segurança.
Fonte: code.claude.com/docs/en/code-review-local (conferido em 24/11/2026)

Code Review automático no PR

Na aula: Code Review gerenciado, ajustado por CLAUDE.md e REVIEW.md (lido da branch base, nunca do próprio PR).
  • Continua sendo o terceiro tamanho: agentes procuram, uma etapa de verificação filtra e os comentários caem no PR.
  • Disponível nos planos Team e Enterprise, com níveis Quick, Standard e Deep.
  • Os três se somam: /code-review antes do PR, ultra no que é crítico, e o automático no PR.
Fonte: code.claude.com/docs/en/code-review (conferido em 24/11/2026)
