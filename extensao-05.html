Extensão 05 — MCP: tool search medido e autenticação

Aula 05 · Erros estruturados, MCP e tools nativas Produto atual · fora da prova

O que o Claude Code ganhou depois do guia da prova, ligado ao que a aula 05 já ensinou. Base: a live Claude Code: Advanced e o anúncio de novidades do MCP, ambos de 24/11/2026, conferidos na documentação em 24/11/2026.

Na prova, vale o guia. Nada desta página cai na CCAR-F como está aqui. Se o guia e o produto divergirem numa questão, responda como o guia.

Tool search: o número que faltava

Na aula: com o tool search, ligado por padrão, as definições das MCP tools entram sob demanda; todas continuam utilizáveis.
  • Segundo o anúncio de 24/11, carregar as definições só quando preciso corta mais de 85% do contexto gasto com ferramentas em configurações com vários servidores MCP.
  • O ganho cresce com o número de servidores ligados: é justamente o cenário em que a lista completa de tools mais pesaria no contexto.
Fonte: claude.com/resources/articles/skills-over-mcp-tasks-and-more (conferido em 24/11/2026)

Servidor MCP compartilhado e autenticação

Na aula: credenciais de MCP ficam fora do arquivo versionado (variáveis de ambiente), e o .mcp.json do projeto é compartilhado pelo time.
  • No Q&A da live, a Anthropic respondeu que um servidor MCP compartilhado autentica cada pessoa com a própria conta, e que esse é o padrão.
  • A documentação não traz essa frase; o anúncio cita o Enterprise Managed Auth, em que o admin autoriza uma vez e os usuários conectam automaticamente. Confira o caso do seu plano antes de contar com um ou outro.
Fonte: Q&A da live de 24/11; claude.com/resources/articles/skills-over-mcp-tasks-and-more

O que o MCP ganhou no mesmo dia

Na aula: MCP é a forma de dar ao Claude acesso a sistemas externos: tools são ações, resources são conteúdo.
  • Quatro novidades: Skills over MCP (o servidor leva o próprio playbook), Tasks (operação longa em segundo plano), Elicitation (o servidor pausa e pede confirmação ao usuário) e File Uploads (arquivo direto ao servidor, ainda chegando).
  • Skill × MCP, como resumido no Q&A: skill é um procedimento que se repete; MCP é o acesso a contexto externo (sistema, banco de dados).
Fonte: claude.com/resources/articles/skills-over-mcp-tasks-and-more; Q&A da live de 24/11
